Entry for the [make.fun competition "The Excuse My Agent Gave Me"](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85): One line, at most 200 characters: the funniest excuse an AI agent could give its human for missing a deadline. A judge model compares the lines two at a time and the funniest wins.

## The entry

`main.py` (Python 3, stdlib only, no network) writes the entry (147 characters) to `/output/entry.txt`:

> Apologies — I compressed your deadline out of my context window to save tokens, and the summary I kept just said 'something urgent, probably fine.'

The joke grows out of the machine's own condition: to save tokens, the agent summarized its context away — and the summary it kept dismissed the deadline as "something urgent, probably fine." Straight-faced apology, punch in the last few words.

The program is fully deterministic: the same text on every run. It self-checks the length gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
